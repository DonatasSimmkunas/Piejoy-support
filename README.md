# Piejoy support

Piejoy turns photographed or imported English recipes into grocery checklists on your iPhone. Text recognition and the bundled recipe library work on device. No account is required.

For help, email donatas@edvconsult.no. Include the app version and a short description of the problem; do not send passwords or payment details.

- Import recipe photos, tap Recipe finished, review the recognized ingredients and save the recipe.
- Check camera permission in iPhone Settings if capture is unavailable.
- Use Restore purchases on the Unlimited recipes screen with the same Apple Account that bought the subscription. Manage or cancel subscriptions in your Apple Account.
- Export any recipes you need before removing the app.
